# 3D Block Wars — MIT-Based Voxel Starter

A first-person 3D block arena with BedWars-style islands, bed defenses, bridging blocks, enemy PvP, coins, shop purchases, and respawn/victory states.

## Run

Serve the folder through HTTP:

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` and click the game.

## Controls

- **WASD** — move
- **Mouse** — look
- **Space** — jump
- **Shift** — sprint
- **Left click** — break a block or attack/bed hit
- **Right click** — place a block
- **1–5** — wool, wood, stone, glass, lantern
- **Q** — item shop
- **Esc** — release pointer lock

This project is an original implementation inspired by the BedWars genre. It does not reproduce Bloxd.io source code or proprietary assets.
