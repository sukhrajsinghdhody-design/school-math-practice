# Block Wars

A revised 3D BedWars-inspired solo prototype built in Three.js.

## Features

- First-person mouse look and pointer-lock controls
- WASD movement, sprint, jump, gravity, and voxel AABB collision
- Two team islands, bridge, center island, and bed defenses
- Cyan bed respawn anchor and destroyable Red bed
- Rivals, sword combat, hit points, respawn/elimination
- Coal and Iron resource generation
- Wool, wood, stone, healing, and sword shop purchases
- Block targeting, placement, and breaking

## Run

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` and click **PLAY MATCH**.

## Controls

- **WASD** move · **Mouse** look · **Space** jump · **Shift** sprint
- **Left click** attack or break · **Right click** place a block
- **1–5** select block · **Q** shop · **Esc** release mouse
